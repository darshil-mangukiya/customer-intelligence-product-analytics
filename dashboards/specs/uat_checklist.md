# Stakeholder UAT Checklist

User acceptance checklist for analytics stakeholders.

## Executive

- Can answer top risks, opportunities, KPI movement, and priority actions.

## Customer Analytics

- Can filter churn, CLV, cohort, segment, and activation outputs.

## Product Analytics

- Can identify return-heavy, low-margin, retention-driving, and cross-sell products.

## BI Engineering

- Can trace each visual to a governed mart and metric definition.
