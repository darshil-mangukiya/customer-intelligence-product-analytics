# Reverse ETL Activation Design

Activation-ready design for CRM and lifecycle use cases.

## Exports

- High churn risk, win-back, high CLV, cross-sell, loyalty upgrade, and discount-sensitive customers.

## Schema

- customer_id, segment, churn_probability, clv_band, recommended_action, recommended_product_category, priority_score, campaign_reason.

## Controls

- Exports are generated as local, CRM-style activation files with schema and control notes for downstream integration.
